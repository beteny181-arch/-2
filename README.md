# شركة الحاج جمعة السحابة - النظام المحاسبي الشامل للنفقات والمصروفات ومراكز التكلفة 📊🚀

موقع إلكتروني محاسبي تفاعلي متطور مصمم خصيصاً لتحليل واستعراض كافة نفقات ومصروفات ومراكز تكلفة **شركة الحاج جمعة السحابة**.

## 🌟 مميزات وتفاصيل الموقع:
- **📈 1. قائمة الدخل (P&L Income Statement):** إجمالي المبيعات، تكلفة البضاعة المباعة (COGS)، هامش الربح، وصافي ربح/خسارة.
- **🚜 2. مراكز التكلفة والسيارات:** تحليل نفقات الآلات والمعدات، التريسكل، العربية الملاكي، الموتوسيكل، والعربية النقل.
- **📊 3. تحليل وتطور المصروفات:** مقارنة شهري الفروقات (+/-) من فبراير إلى يونيو.
- **📑 4. سجل القيود اليومي (599 قيد):** محرك بحث وتصفية فورية حسب البيان، التاريخ، الحساب، والمستخدم.
- **📥 رفع وتحديث الإكسيل:** إمكانية سحب وإسقاط أي ملف إكسيل جديد لتحديث كافة القوائم والرسوم البيانية فوراً.
- **🔗 مشاركة التقرير التنفيذي:** صفحة `share.html` مخصصة للعرض التنفيذي بدون صندوق الرفع.

## 🚀 كيفية الرفع التشغيل على GitHub Pages:
1. قم بإنشاء Repository جديد على حسابك في GitHub.
2. فك الضغط عن هذا الملف و ارفع الملفات (`index.html`, `share.html`, `data.json`, `README.md`).
3. اذهب إلى **Settings** ⬅️ **Pages** ⬅️ واختر الفرع **Main / master** ثم اضغط **Save**.
4. ستحصل فوراً على رابط موقع دائم مجاني على إنترنت!
