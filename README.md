# شركة الحاج جمعة السحابة - التقرير المحاسبي التنفيذي 📊🚀

موقع إلكتروني محاسبي تفاعلي يعرض نتائج ونفقات ومصروفات ومراكز تكلفة **شركة الحاج جمعة السحابة** (نتائج التقرير فقط).

## 🌟 مميزات التقرير المباشر على GitHub Pages:
- **📈 1. قائمة الدخل (P&L Income Statement):** إجمالي المبيعات، تكلفة البضاعة المباعة (COGS)، هامش الربح، وصافي ربح/خسارة.
- **🚜 2. مراكز التكلفة والسيارات:** تحليل نفقات الآلات والمعدات، التريسكل، العربية الملاكي، الموتوسيكل، والعربية النقل.
- **📊 3. تحليل وتطور المصروفات:** مقارنة شهري الفروقات (+/-) من فبراير إلى يونيو.
- **📑 4. سجل القيود اليومي (599 قيد):** محرك بحث وتصفية فورية حسب البيان، التاريخ، الحساب، والمستخدم.

## 🚀 كيفية التحديث ورفع التقرير على GitHub Pages:
1. افتح صفحة `admin.html` على جهازك لرفع أي شيت إكسيل جديد وتحديث البيانات.
2. اضغط زر **"تحميل ZIP لـ GitHub 📦"**.
3. ارفع الملفات (`index.html`, `share.html`, `admin.html`, `data.json`, `README.md`) على مستودع GitHub الخاص بك.
4. اذهب إلى **Settings** ⬅️ **Pages** اختر فرع **Main** واضغط **Save**.
5. سيعرض رابط GitHub Pages **النتائج فقط لجميع الزوار** بدون مربع الرفع!
